# Contributing

Thank you for your interest in Flake Desktop.

## Before opening a pull request

1. Open an issue first for substantial changes so the project direction can be discussed.
2. Keep changes focused and explain the user-visible effect.
3. Do not remove third-party copyright or license notices.
4. Do not add telemetry, background network calls or data collection without explicit review and documentation.
5. Never make destructive PC Manager actions silent. Uninstall operations must require clear user confirmation.

## Pull requests

- Describe the problem and the proposed solution.
- Include screenshots for visual changes where possible.
- Include build/test results and known limitations.
- Keep the application free; do not add paywalled features or subscription checks.

The maintainer reviews and approves changes before they enter the official branch or a release. A contribution does not guarantee inclusion.
